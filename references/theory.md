# 理论来源与应用边界

本 skill 依据《谈美》本身，不将其等同于朱光潜全部时期的美学，也不混用《谈美书简》。以下“视频应用”是创作推演，不是朱光潜论述摄影机或生成模型的原话。

| 原著位置 | 理解要点 | 视频应用及边界 |
|---|---|---|
| 第1章，三种态度 | 实用、科学、美感的区别在注意对象与心理活动；美感专注于具体形象。 | 在履行商业或教育用途时，仍组织可感知的形象。不能据此一概删除信息或CTA。 |
| 第2章，心理距离 | 与实际利害保持适当距离；过近受牵绊，过远难理解。情感要经过艺术转化。 | 距离是观看关系，不等于远景、少特写、少情绪或固定含蓄风格。 |
| 第3、7章，移情与心物关系 | 人的情趣与物的姿态相互影响，美有主体和对象共同参与。移情不等于全部美感。 | 用具体姿态和音画关系承载情感；不能把任意情感投射当作足够理由。 |
| 第4—6章，清理误解 | 快感、联想、考证、批评与欣赏不同。 | 信息和刺激可以有作用；评价作品时不能只统计它们。 |
| 第8—10章，艺术与创造 | 艺术不止于复制自然或选择漂亮材料。游戏与艺术共享自由创造的特点；艺术还须形成可传达的作品。想象选择材料并作新的综合。 | 可以写实、抽象、夸张或欢快；选材与组织赋予统一性。联想在创造中有作用，散漫联想却可能妨碍欣赏。 |
| 第11—14章，创作的条件 | 情感引导意象；格律与技巧使表达成为可能；模仿是学习途径；灵感需要积累与功夫。 | 内化参考片的组织方法，保留自己的本色细节。反复比较和修订有价值，但不自动授权付费重试。 |
| 第15章，人生的艺术化 | 完整人生包含实用、科学、美感活动；本色、真诚、人格完整与严肃生活相连。 | 审美可以进入日常与商业，不是逃避生活或给生活加滤镜。真实素材与虚构方案须清楚区分。 |
